# 三分钟面试演示

## 0:00 — 0:30：问题与范围

介绍同一销售团队可能面对组织合作和消费者咨询两种任务。作品把两者放进统一体验，但保留不同训练目标。主动说明所有业务资料虚构，默认使用规则模拟。

## 0:30 — 1:30：TOB 对话

选择新店拜访，先问门店工作量和责任顾虑。用产品卡解释服务内容及排除项，再提出一个可复盘的小范围试点。展示对方追问，以及结束后引用原话的覆盖提示。

## 1:30 — 2:10：TOC 和角色互换

切换车主场景，说明需求探索与自主决策的重要性。展示角色互换会开始新会话，避免上下文和角色混杂。不要把覆盖数量解释为销售能力分数。

## 2:10 — 3:00：工程取舍

展示独立产品数据、会话隔离、服务器模型适配、测试和发布扫描。说明无依赖启动是为了降低面试体验成本；同时如实说明未完成语音、生产部署和模型评分。

简历描述建议：构建支持 TOB/TOC 双场景的销售沟通训练 Demo，实现角色隔离、产品事实卡、可解释规则复盘及公开数据检查；提供无密钥模拟模式与服务端模型接口适配。

根据本人真实参与情况调整描述，不添加未经验证的提效比例、上线规模或商业结果。
